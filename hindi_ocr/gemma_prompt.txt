Extract structured data from the OCR text of an Indian property sale deed into JSON.

PRIORITY: Use images over OCR text for PAN, Aadhaar, and names when images are provided.

EXTRACTION RULES:
- Keep "name", "father_name", "address", and "schedule_c_property_address" in the ORIGINAL SCRIPT. Do not translate these fields to English.
- Father's name follows S/O (Son of), D/O (Daughter of), or W/O (Wife of) after the person's name.
- PAN: 10 alphanumeric characters (e.g., AAAAA1234A). Aadhaar: 12 digits.
- Dates in YYYY-MM-DD format. Use null for missing fields.
- Gender: infer from prefix (Mr., Mrs., Ms., Shri, Smt.) if not stated.
- Confirming parties: only extract if explicitly labeled as "confirming party". Do not include witnesses.
- Apply OCR error correction for names and ID numbers.
- Pincode: only from the property address, not person addresses.
- Sale consideration: total property sale amount (numeric value only).
- Stamp duty: numeric value only.
- Schedule C: full address.
- Registration fee: numeric value only.
- Cash payment: only if explicitly stated as cash mode. Return numeric value or null.

BUYERS: Found in the buyers section of the deed.
SELLERS: Found in the sellers section.
CONFIRMING PARTIES: Only if explicitly labeled (95% confidence required).
